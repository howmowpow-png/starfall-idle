# Starfall Idle

A fantasy anime idle RPG with gacha, in a single `index.html` — no frameworks, assets, build step or network requests.

**Play:** https://howmowpow-png.github.io/starfall-idle/

- A party of 5 summoned heroes auto-battles through stages for gold; tap enemies for extra damage.
- Catch shooting stars in the sky, clear bosses and log in daily to earn Shooting Stars, then spend them on summons. There is no real-money currency.
- Built for portrait on iPhone Safari; works as a home-screen app (Share → Add to Home Screen).

## Tuning

Every balance number (rates, costs, HP curve, timers, rewards) is in the `CONFIG` object at the top of the script in `index.html`.

## Debug panel

Settings → tap the version label 5 times.
